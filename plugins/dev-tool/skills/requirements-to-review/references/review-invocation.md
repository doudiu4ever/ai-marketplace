# 各平台审核调用方式

各平台按本机实际能力调用。把 [SKILL.md 的审核口径](../SKILL.md#审核口径) 连同需求、非目标、验收条件、实施进度、搬迁映射及审核忽略区传给 reviewer，并明确告知测试脚手架的审核边界（仅聚焦误判通过、宿主机/仓库副作用及标准测试环境可执行性，不对非常规极端环境变量或特殊路径字符做防御性扩写）。只能接收裸 diff 的入口仅用于补充检查。

复审提示须附上上轮报告、逐项处理结果和最新忽略区（满足 [SKILL.md 处理每轮结果第 5 步](../SKILL.md#处理每轮结果) 的零改动边缘忽略收口条件时除外）。请 reviewer 独立审核当前全部未提交变更，重点核对本轮修复及其直接影响；若生产代码在先前轮次已审过无问题且本轮未改动，在提示中明确标出，避免围绕测试脚手架边缘假设发散。对于上轮重复提出的忽略项，明确其适用边界，请 reviewer 仅在新改动或新证据表明实际影响超出该边界时再次列为发现。要求 reviewer 明确给出本轮问题清单或无问题结论。

- **Codex**：先查 `codex review --help`。用 `codex review -` 从标准输入传入完整提示，明确读取任务文档及全部已暂存、未暂存和未跟踪内容。无法附带任务上下文的 `codex review --uncommitted` 仅用于补充检查。不假定自定义 prompt 可与 `--uncommitted` 组合，也不假定自动继承主会话上下文。
- **Claude Code**：允许委派时可用独立只读 reviewer 子代理传入完整审核上下文，不假定预装 `code-reviewer`。支持独立 CLI 时先查 `claude --help`，用 `claude -p` 并通过工具/权限限制写入，保留只读能力或提供完整材料；不虚构 `claude review`；禁止嵌套会话时改用允许的能力或手动独立会话，不绕过限制。
- **Antigravity (agy)**：无内置 `agy review`。前置确认按本机能力列选项，默认推荐同宿主支持完整上下文的独立只读能力：① 允许委派时，用内置只读 `research` 子代理、无写工具的自定义只读子代理，或允许模型调用且真正委派独立只读 reviewer 的已安装 skill/子代理（仅在当前会话展开提示词的不算，跳过）；② 外部审核 CLI（如本机可用的 `codex review`）仅在用户选定或预先授权后调用；③ 独立 `agy -p` / `--print` 仅在允许嵌套会话且能强制工作区只读（如只读代理或无写权限配置）时使用（先查 `agy --help`，`--sandbox` 或仅传 diff 不算只读保护）；禁止嵌套时跳过 CLI。选手动方式，或缺少已授权且支持完整上下文的自动只读能力时，用手动独立会话，不绕过限制。
- **手动交互**：用户选择手动方式时，在对应客户端的独立审核会话或可用审核入口中发起审核，取得真实结果后继续。`/review` 等交互命令须以当前客户端支持情况为准，不能当作通用 shell 命令。
- 所选审核方式不可用或结果无法获得时，记录受阻并说明可选替代方式；切换用户明确指定的工具前取得确认。普通自查不能冒充独立审核，也不能因缺少某一客户端就认定当前客户端无法审核。
